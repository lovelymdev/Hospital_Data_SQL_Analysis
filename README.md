# 🏥 Hospital Data SQL Analysis

## Project Overview
This project demonstrates SQL data analysis using a Hospital Dataset.
The objective is to analyze hospital records and answer real-world business questions using PostgreSQL.

## Tools Used
- PostgreSQL
- SQL
- Excel (CSV Dataset)

## Dataset
Hospital_Data.csv
The dataset contains information about:
- Hospital Name
- Location
- Department
- Doctors Count
- Patients Count
- Admission Date
- Discharge Date
- Medical Expenses

## Business Questions Solved
✔ Total number of patients
✔ Average doctors per hospital
✔ Top 3 departments with highest patients
✔ Hospital with highest medical expenses
✔ Average medical expenses per day
✔ Longest hospital stay
✔ Total patients by city
✔ Average stay by department
✔ Department with lowest patients
✔ Monthly medical expenses report
